# Rapport J1 + J2 — socle, journal, authentification

## 1. Exigences terminées et tests
- **Socle** : TypeScript strict, Fastify 5, SQLite (WAL, `synchronous=FULL`, `BEGIN IMMEDIATE`), migrations numérotées (`001_init.sql` = annexe B, `002_auth.sql`), ESLint (interdit `Math.random`, `any`, `eval`).
- **I-01, I-05, I-06** : initialisation complète (`npm run init`), autorité locale et certificat serveur générés sans OpenSSL, TLS obligatoire, empreinte publiée.
- **J-01, J-02, J-03, J-06** : journal chaîné, vecteurs de l'annexe C reproduits, points de contrôle Ed25519, événements de sécurité dans la chaîne.
- **A-01 à A-08, U-01 à U-03, I-02** : configuration initiale, connexion avec TOTP, verrouillage, limitation de débit, sessions, CSRF, ré-authentification, en-têtes, comptes, matrice des droits testée cellule par cellule contre la spécification.
- 166 tests en 7 fichiers, tous verts. `npm audit` : 0 vulnérabilité.

## 4. Points à faire relire par un humain
- `server/src/security/x509.ts` : encodeur DER écrit à la main (validé par `openssl verify -purpose sslserver` et une poignée de main TLS, mais c'est du code cryptographique sensible).
- `server/src/http/hooks.ts` : ordre des contrôles (débit, configuration, session, CSRF, restriction, droits).
- Le défi TOTP est gardé en mémoire : un redémarrage du serveur oblige à recommencer la connexion (choix voulu).
