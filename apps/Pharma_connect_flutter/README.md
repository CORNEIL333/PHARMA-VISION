# PharmaConnect Flutter

Nouveau squelette Flutter de PharmaConnect, créé à côté du gitlink historique `apps/Pharma_connect`.

## Démarrer

Avec Flutter installé :

```sh
flutter pub get
flutter run
```

Pour générer les projets de plateforme natifs (Android, iOS, etc.) dans ce dossier :

```sh
flutter create .
```
